Machine Test Console

An Angular admin built for the beginner machine test: authentication, role based access, user management, image handling and a Drive style file browser — all against a json-server mock API.

  • Route guards and an HTTP interceptor for tokens
  • Server-side search, filters and pagination
  • Multiple image upload with a product-style zoom
